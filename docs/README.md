# Audiobook Librarian Documentation

Welcome to the Audiobook Librarian API documentation. This repository contains documentation for the API, including OpenAPI specifications, usage guidelines, and development information.

## Overview

The Audiobook Librarian API provides endpoints for managing audiobook collections, including books, series, authors, and user information. The API is documented using the OpenAPI Specification (formerly known as Swagger).

## Documentation Structure

This documentation is organized into the following sections:

- [API Documentation](./API.md) - Details about the API, including endpoints, authentication, and usage
- [Installation](./INSTALLATION.md) - Cross-platform setup, HTTPS, storage paths, scheduler/cron, queue workers, and maintenance jobs
- [Development Guidelines](./DEVELOPMENT.md) - Information for developers contributing to the API documentation
- [Changelog](./CHANGELOG.md) - History of changes to the API and documentation
- [Reading Progress & Statistics Requirements](./requirements/reading-progress-and-stats.md)

## Quick Links

### OpenAPI Specification

- **JSON Format**: [`openapi.json`](./openapi.json) - The complete OpenAPI specification (source of truth)
- **Public URL**: `https://<your-server>/api-docs/openapi.json` - Use this URL for API client generation on your instance

## Getting Started

To get started with the API:

1. Review the [API documentation](./API.md) to understand available endpoints
2. Use the OpenAPI JSON URL to generate API clients or explore the API using Swagger UI
3. Check the [Development Guidelines](./DEVELOPMENT.md) if you plan to contribute to the API documentation
