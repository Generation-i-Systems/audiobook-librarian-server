# librarian.json Format Reference

This document describes the canonical structure of the `librarian.json` file that lives alongside each book directory. The file is generated by `App\Traits\HandlesLibraryJson` (see `prepareBookDataForJson()`), which should be treated as the single source of truth. Update this document whenever that method changes.

## Top-Level Schema

The JSON document is an object with the following keys. Unless marked as optional, keys are always present (although values may be `null`).

| Key | Type | Description |
| --- | --- | --- |
| `id` | integer | Primary key of the book. |
| `title` | string | Display title of the book. |
| `description` | string\|null | Long-form description. |
| `release_date` | string\|null | ISO-8601 date (YYYY-MM-DD) when available. |
| `isbn` | string\|null | ISBN identifier, if known. |
| `language` | string | Two-letter language code (defaults to `"en"`). |
| `duration` | integer\|null | Duration in seconds. |
| `duration_formatted` | string\|null | Human-readable duration (e.g., `"10:42:15"`). |
| `file_size` | integer\|null | Size in bytes of audio assets. |
| `file_size_formatted` | string\|null | Human-readable file size (e.g., `"1.2 GB"`). |
| `cover_image` | string\|null | Relative path to the cover image inside the book directory. |
| `authors` | array<object> | Array of author records (see below). |
| `narrators` | array<object> | Array of narrator records (see below). |
| `genres` | array<object> | Array of genre records (see below). |
| `series` | object\|null | Series metadata when the book belongs to a series. |
| `publisher` | object\|null | Publisher metadata. |
| `created_at` | string\|null | Database creation timestamp (ISO-8601). |
| `updated_at` | string\|null | Database update timestamp (ISO-8601). |
| `metadata` | object | Generation metadata (see below). |

### Author / Narrator Object

```
{
  "id": 123,
  "name": "Jane Example",
  "sort_name": "Example, Jane"
}
```

* `sort_name` may be `null`.

### Genre Object

```
{
  "id": 42,
  "name": "Science Fiction",
  "slug": "science-fiction"
}
```

* `slug` may be `null`.

### Series Object

```
{
  "id": 5,
  "name": "Example Saga",
  "number_in_series": "03",
  "is_collection": false
}
```

* Entire object is omitted (`null`) if the book is not attached to a series.
* `number_in_series` is stored as a string so leading zeroes can be preserved.

### Publisher Object

```
{
  "id": 17,
  "name": "Example Press"
}
```

* Entire object is `null` if no publisher is linked.

### Metadata Object

```
{
  "source": "import",
  "imported_at": "2025-10-05 12:34:56",
  "version": "1.0"
}
```

* `source` identifies how the book was ingested (`import`, `manual`, etc.).
* `imported_at` mirrors the book’s `created_at` when available.
* `version` tracks the schema revision of this JSON format.

## Example `librarian.json`

```json
{
  "id": 101,
  "title": "The Example Adventure",
  "description": "A daring tale of documentation.",
  "release_date": "2024-03-15",
  "isbn": "9780000000000",
  "language": "en",
  "duration": 37200,
  "duration_formatted": "10:20:00",
  "file_size": 1234567890,
  "file_size_formatted": "1.15 GB",
  "cover_image": "cover.jpg",
  "authors": [
    {
      "id": 11,
      "name": "Alex Writer",
      "sort_name": "Writer, Alex"
    }
  ],
  "narrators": [
    {
      "id": 21,
      "name": "Taylor Voice",
      "sort_name": null
    }
  ],
  "genres": [
    {
      "id": 31,
      "name": "Adventure",
      "slug": "adventure"
    }
  ],
  "series": {
    "id": 41,
    "name": "Example Series",
    "number_in_series": "01",
    "is_collection": false
  },
  "publisher": {
    "id": 51,
    "name": "Docs Unlimited"
  },
  "created_at": "2025-10-05T12:00:00Z",
  "updated_at": "2025-10-06T08:30:00Z",
  "metadata": {
    "source": "import",
    "imported_at": "2025-10-05 12:00:00",
    "version": "1.0"
  }
}
```

## Maintenance Notes

* Always regenerate this document after changing `prepareBookDataForJson()` so documentation and implementation stay in sync.
* Tests and tools that validate `librarian.json` should reference this schema rather than duplicating hard-coded expectations.
