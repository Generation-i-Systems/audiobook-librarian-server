Anytime you make changes to the codebase, commit them frequently with small, focused commits that describe the changes clearly. Multiple small commits are better than few large commits. Each commit should represent a single logical change or feature.

- Commit often and keep commits small
- Write clear, concise commit messages
- Group related changes together
- Avoid committing broken code
- Test your changes before committing
- Keep commits focused on a single purpose
- Make sure each commit is buildable and functional
- Include relevant context in commit messages for future reference
